# Learning roadmap

```text
Cargo → syntax → ownership → errors/data modeling → traits/iterators → lifetimes
      → concurrency → async → networking → unsafe/internals → performance
      → storage/databases → distributed systems → integrated projects
```

Each stage builds vocabulary needed by the next. Experienced readers can jump by subject, but should revisit ownership relationships before lifetimes, shared-memory concurrency, pinning, or unsafe abstractions.
