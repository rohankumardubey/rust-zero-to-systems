# Rust Zero to Systems

This book is the guided interface to a repository of executable lessons. It grows from stable Rust fundamentals into systems and distributed-systems engineering without hiding the connection between explanation and code.

The project is incomplete by design while phases are in progress. The machine-readable manifest reports only inventoried concepts; audit pages track broader baselines. Start with the [learning roadmap](roadmap.md), or jump to a subject when revising.

The baseline is stable Rust 1.98.1, edition 2024, reviewed 2026-09-19. Nightly-only, historical, experimental, ecosystem, external-service, and hardware-specific material is labeled separately.
