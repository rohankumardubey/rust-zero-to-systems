# Curated ecosystem baseline

Ecosystem coverage is intentionally selective and time-sensitive. Review categories include async, concurrency, web/HTTP/RPC, serialization, CLI/errors/configuration, logging/tracing/metrics, databases/ORM, data/Kafka/object storage, cloud/AWS/Kubernetes, WebAssembly, desktop/GUI/games, embedded, FFI, parsing/regex, crypto, compression, date/time, testing/fuzzing/benchmarking/profiling.

Every adopted technology needs official docs/repository links, an example location, alternatives/tradeoffs, stability classification, and a review date in `docs/ecosystem-status.md`.

Status: taxonomy established; no framework adoption is claimed yet.
