# Standard library baseline

Primary baseline: [stable standard library documentation](https://doc.rust-lang.org/stable/std/).

Audit API families rather than every tiny method: primitive types; collections; iterators; option/result; formatting/comparison/operators; strings/slices; memory/pointers; cell/borrow; smart pointers; fs/io/path/process/env/time; net; thread/sync/atomics; future/task/pin; panic; FFI and OS interfaces.

Status: not reconciled. Planned primarily for Phases 3–6 and 9, with final audit in Phase 19.
