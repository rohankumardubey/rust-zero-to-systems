# Macro baseline

Primary baselines: Rust Reference macro chapters, Rust Book, and proc-macro API documentation.

Audit: declarative syntax, fragment specifiers, repetition, recursion, hygiene/scoping; procedural token streams; derive, attribute, and function-like macros; parsing and generation with `syn`/`quote`; testing and diagnostic quality.

Status: `println!` is linked as a planned introductory concept; systematic coverage is Phase 8.
