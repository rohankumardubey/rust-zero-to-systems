# Unsafe Rust baseline

Primary baselines: Rust Reference unsafe/behavior/layout chapters, Rustonomicon, stable pointer/memory APIs, and Miri documentation.

Audit: unsafe blocks/functions/traits; raw pointers and arithmetic; aliasing/alignment/provenance; representations/layout/padding; initialization/drop control; `NonNull`/`UnsafeCell`; unions/FFI; soundness and UB; safety contracts; safe abstractions; Miri workflows.

Status: planned for Phase 8. Every complete record must document invariants and containment.
