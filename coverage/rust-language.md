# Stable Rust language baseline

Primary baselines: [Rust Reference](https://doc.rust-lang.org/reference/), [Rust Book](https://doc.rust-lang.org/book/), and [Edition Guide](https://doc.rust-lang.org/edition-guide/).

Audit families: lexical structure and macros; items/attributes; crates/modules/visibility; statements/expressions; values/types; bindings/patterns; functions/closures; structs/enums/unions; traits/generics; implementations; coercions/casts; destructors; concurrency language traits; unsafe operations; ABI/linkage; conditional compilation.

Status: Phase 2 is in progress. The manifest covers bindings, values, text, functions/control flow, basic data types/modules, comments/raw identifiers, attributes/configuration, conversions, aliases, function pointers, and the never type. References and raw pointers, union access, and deeper crate/package organization remain assigned to later ownership/unsafe/tooling work; Phase 19 performs the complete reconciliation.
