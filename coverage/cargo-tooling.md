# Cargo and tooling baseline

Primary baselines: [Cargo Book](https://doc.rust-lang.org/cargo/), [rustc book](https://doc.rust-lang.org/rustc/), rustdoc, rustfmt, Clippy, and rustup documentation.

Audit families: packages/crates/targets; manifests and dependency sources; features/resolution; workspaces; profiles; build scripts; tests/benches/examples; publishing; configuration/environment; lockfiles; rustdoc; linting/formatting; target/toolchain management; cross compilation; edition migration.

Status: foundational workspace/tooling is inventoried structurally but detailed lessons are not reconciled.
